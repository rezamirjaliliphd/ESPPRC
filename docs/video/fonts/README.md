# LaTeX typography

These four **unmodified** OpenType files are a subset of Latin Modern:

- `lmroman10-regular.otf` and `lmroman10-bold.otf`: Latin Modern Roman.
- `lmmono10-regular.otf`: Latin Modern Mono for code.
- `latinmodern-math.otf`: Latin Modern Math for mathematical symbols.

Latin Modern extends Donald E. Knuth's Computer Modern design. Text fonts:
copyright 2003–2009 Bogusław Jackowski and Janusz M. Nowacki, on behalf of
TeX Users Groups. Math extensions: copyright 2012–2014 Bogusław Jackowski,
Piotr Strzelczyk and Piotr Pianowski, on behalf of TeX Users Groups.

The files retain the **GUST Font License**, included in `GUST-FONT-LICENSE.txt`;
they are not relicensed under the ESPPRC project's MIT license. Upstream
readmes and manifests are preserved alongside this file. Complete upstream
distributions are available at [Latin Modern on CTAN](https://ctan.org/pkg/lm)
and [Latin Modern Math on CTAN](https://ctan.org/pkg/lm-math).

Source for this copy: Ubuntu `fonts-lmodern` version `2.004.5-6.1`. The render
script registers these fonts only inside its process; no system-font install
is needed. Their purpose is to reproduce the requested LaTeX typography.
